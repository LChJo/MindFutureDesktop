# DevTools 会话分析器

DevTools 是一个内置的 Claude Code 会话分析工具，可以读取 `~/.claude/projects/` 下的 JSONL 会话日志，提供 Token 用量统计、费用估算、工具调用可视化、子代理执行树和实时会话监控等功能。

## 功能概述

| 功能 | 说明 |
|------|------|
| 项目浏览 | 自动扫描所有 Claude Code 项目，按最近活动排序 |
| 会话列表 | 每个项目下的会话列表，显示首条消息预览、Token 数和费用 |
| 对话查看 | 完整的用户/助手消息流，包含工具调用和子代理 |
| Token 统计 | 输入/输出/缓存读取/缓存创建的 Token 分类统计 |
| 费用估算 | 基于模型定价（Opus/Sonnet/Haiku）的费用自动计算 |
| 工具调用卡片 | 可展开的工具调用详情，显示输入参数和返回结果 |
| 子代理树 | Task 工具创建的子代理执行树，含独立指标和消息 |
| 实时监控 | 文件变化自动检测，活跃会话实时刷新 |

## 打开方式

双击桌面上的 **DevTools** 图标（图标：📈）即可打开 DevTools 窗口。

## 界面说明

DevTools 窗口分为两个区域：

### 左侧边栏

- **搜索框**：输入关键词过滤项目列表（支持项目名和路径匹配）
- **项目列表**：点击项目名可展开/折叠该项目下的会话列表
  - 每个项目显示会话数量角标
  - 绿色圆点表示正在进行的活跃会话（最近 5 分钟内有写入）
- **会话条目**：点击选中一个会话，右侧区域将加载完整内容
  - 显示首条用户消息的前 120 个字符作为预览
  - 右侧显示 Token 总量、费用和相对时间

### 右侧主区域

选中会话后，主区域从上到下包含：

#### 指标栏

水平排列的统计徽章：

| 指标 | 说明 |
|------|------|
| 时长 | 会话首尾消息的时间差（如 `3m 42s`） |
| Token 数 | 总 Token 数（悬停显示输入/输出/缓存明细） |
| 费用 | 基于模型定价的估算费用（如 `$1.23`） |
| 消息数 | 用户 + 助手消息总数 |
| 工具数 | 工具调用总次数 |
| 分支 | Git 分支名（如有） |
| Live | 活跃会话标识（绿色圆点动画） |

#### 对话流

按时间顺序展示的消息列表：

- **用户消息**（蓝色背景）：显示用户输入的文本
- **助手消息**（深色背景）：显示助手回复，包含：
  - 模型标签（Opus / Sonnet / Haiku）
  - Token 用量小标签
  - 文本内容
  - 工具调用卡片
  - 子代理执行树

#### 工具调用卡片

每个工具调用显示为可展开的卡片：

- **折叠状态**：显示工具图标 + 工具名 + 一行摘要
  - Read → `Read src/main.ts`
  - Bash → `$ npm test`
  - Grep → `Grep "pattern" path`
  - Task → 子代理描述
- **展开状态**：点击卡片头部可展开，查看：
  - **Input**：格式化的 JSON 输入参数
  - **Result**：工具返回结果（超长内容自动截断至 3000 字符）
  - 错误结果会以红色高亮显示

支持的工具图标映射：

| 工具 | 图标 | 工具 | 图标 |
|------|------|------|------|
| Read | 文件 | Write | 编辑 |
| Edit | 代码 | Bash | 终端 |
| Grep | 搜索 | Glob | 文件夹 |
| Task | 流程图 | WebSearch | 地球 |
| LSP | 代码 | Skill | 魔杖 |

#### 子代理树

当助手使用 Task 工具创建子代理时，会显示树形结构：

- **代理卡片**：显示代理 ID、描述、执行时长、Token 数和费用
- **展开查看**：点击可展开代理内部的消息列表
  - 包含代理的用户消息和助手消息
  - 显示代理使用的工具列表

## 数据来源

DevTools 读取的数据位于 `~/.claude/projects/` 目录：

```
~/.claude/projects/
├── -Users-name-project/              # 项目目录（编码后的路径）
│   ├── abc123.jsonl                   # 会话文件
│   ├── def456.jsonl
│   └── abc123/
│       └── subagents/
│           └── agent-xyz.jsonl        # 子代理会话文件
└── -I:-AI-another-project/
    └── ...
```

- 项目目录名是项目绝对路径的编码形式（`/` 替换为 `-`）
- 每个 `.jsonl` 文件是一个完整的会话记录
- 子代理文件位于 `{session_id}/subagents/` 子目录中

## 实时监控

DevTools 在打开时自动启用文件监控：

1. 使用操作系统级文件监控（Windows: ReadDirectoryChanges, macOS: FSEvents）
2. 监控 `~/.claude/projects/` 下所有 `.jsonl` 文件的变化
3. 检测到变化时自动刷新当前查看的会话内容和会话列表
4. 关闭 DevTools 窗口时自动停止监控

## 费用计算说明

费用基于以下模型定价估算（单位：美元/Token）：

| 模型 | 输入 | 输出 | 缓存创建 | 缓存读取 |
|------|------|------|----------|----------|
| Opus | $15/M | $75/M | $18.75/M | $1.50/M |
| Sonnet | $3/M | $15/M | $3.75/M | $0.30/M |
| Haiku | $1/M | $5/M | $1.25/M | $0.10/M |

> **注意**：费用为估算值，实际费用以 Anthropic 账单为准。未识别的模型默认按 Sonnet 定价计算。

## 常见问题

**Q: 为什么项目列表为空？**
A: 确认 `~/.claude/projects/` 目录存在且包含 `.jsonl` 文件。该目录由 Claude Code CLI 在使用时自动创建。

**Q: 为什么某些会话没有费用数据？**
A: 费用计算依赖助手消息中的 `usage` 字段。如果会话使用了自定义 API 路由（如 LLM Router），可能缺少 Token 计数数据。

**Q: 会话显示为 "Live" 但实际已结束？**
A: "Live" 状态基于文件最后修改时间（5 分钟内），如果 Claude Code 异常退出而没有正常关闭会话，标识会在 5 分钟后自动消失。

**Q: 子代理显示不全？**
A: DevTools 会检索两种子代理文件结构：新版 `{session}/subagents/agent-*.jsonl` 和旧版 `agent-*.jsonl`。如果使用了非标准的代理结构，可能无法识别。

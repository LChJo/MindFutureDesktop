# Claude Bot 使用指南

Claude Bot 是 Moonton Claude Desktop 内置的自动化 AI 机器人系统。你可以创建多个独立的 Bot，每个 Bot 都有独立的 AI 身份、对话记忆和渠道配置，可以接入飞书、Telegram、Discord 等平台，自动与用户对话或执行定时任务。

## 核心概念

### Bot 是什么

每个 Bot 是一个独立的 AI 代理实例，拥有：

- **独立身份**：自定义名称、描述和 System Prompt，决定 Bot 的行为风格和职责范围
- **持久记忆**：每个 Bot 有独立的工作目录，包含 `CLAUDE.md`（长期记忆文件）和 `output/`（生成文件目录），对话内容会自动持久化
- **独立渠道**：每个 Bot 可以独立配置飞书、Telegram、Discord 渠道连接
- **Claude Code 能力**：Bot 底层使用 Claude Code SDK，可以读写文件、执行代码、调用 Skills 等工具

### Bot 的运行状态

| 状态 | 含义 |
|------|------|
| 空闲（idle） | 等待消息，可以随时接受新请求 |
| 工作中（working） | 正在处理消息，新消息自动排队 |
| 错误（error） | 上次处理出现异常，可查看错误详情 |
| 已停止（stopped） | 渠道监听已关闭，不接收外部消息 |

## Bot 管理

### 创建 Bot

1. 进入 **Bot 管理** 面板，点击右上角 **+** 按钮
2. 填写以下信息：

| 字段 | 说明 |
|------|------|
| **名称** | Bot 的名字，最多 50 个字符 |
| **描述** | Bot 的职责描述，用于自动生成 System Prompt |
| **模型** | 选择 AI 模型（见下文） |

3. 点击创建，Bot 会出现在列表中

### 配置 Bot

右键点击 Bot 列表中的 Bot，可以进行以下操作：

| 操作 | 说明 |
|------|------|
| **聊天** | 打开直接对话面板 |
| **编辑** | 修改名称、描述、模型 |
| **渠道配置** | 配置飞书 / Telegram / Discord 接入 |
| **定时配置** | 设置定时发送任务 |
| **启动 / 停止** | 控制渠道监听状态 |
| **删除** | 永久删除 Bot 及其数据 |

### 启动与停止

- **启动**：开始监听已配置渠道的消息，Bot 状态变为"空闲"
- **停止**：断开所有渠道连接，停止接收外部消息
- 修改 Bot 配置（名称、模型、描述）后，若 Bot 正在运行，需要重启才能生效

### 直接对话

点击 Bot 右键菜单中的**聊天**，或双击 Bot，可以打开直接对话面板。在面板中：

- 直接输入消息并发送（Enter 发送，Shift+Enter 换行）
- 支持拖拽或选择附件（最多 5 个）
- 可以切换查看 Bot 的**输出文件**（`output/` 目录内容）
- 可以选择隐藏 System 级消息，只看对话内容

## AI 模型与 System Prompt

### 支持的模型

| 模型 | 说明 |
|------|------|
| **auto**（默认） | 自动选择，默认使用 Sonnet |
| **Sonnet** | 速度与能力均衡，适合大多数场景 |
| **Opus** | 最强推理能力，适合复杂任务 |
| **Haiku** | 最快响应速度，适合简单问答 |
| **自定义提供商** | 使用在应用设置中配置的第三方 LLM 提供商 |

自定义提供商在**应用设置 → Coworks 模型配置**中管理，支持兼容 OpenAI API 的任意服务。

### System Prompt

创建 Bot 时，系统根据你填写的名称和描述**自动生成** System Prompt，包含：

- Bot 的身份定义（名称 + 描述）
- 工作目录结构说明（CLAUDE.md、output/、workspace/）
- 行为规范（精确执行指令、完成后报告结果）
- 记忆管理规则（避免写入冗余信息）
- Skills 使用说明（可通过 `/skills` 命令列出可用技能）

编辑 Bot 描述时，System Prompt 会自动随之更新。

### 自动记忆压缩

每 **8 轮对话**，Bot 会自动触发一次记忆整理：读取 `CLAUDE.md`，将有长期价值的信息归纳到记忆部分，清理过期内容，保持记忆文件简洁（≤15 行核心记忆）。

## 渠道配置

Bot 支持三种外部渠道接入，可同时启用多个：

| 渠道 | 所需凭证 |
|------|------|
| **飞书** | App ID + App Secret（+ 可选 Chat ID） |
| **Telegram** | Bot Token（+ Chat ID） |
| **Discord** | Bot Token（+ Channel ID） |

各渠道配置入口：右键 Bot → **渠道配置** → 选择对应标签页。

配置完成后点击**测试连接**，状态变为**已连接**后启用即可。

## 飞书机器人配置

### 第一步：创建飞书应用

1. 打开 [飞书开放平台](https://open.feishu.cn/)，登录开发者账号
2. 进入**开发者后台** → **创建企业自建应用**
3. 填写应用名称和描述，创建完成后进入应用详情页
4. 在**凭证与基础信息**页面，获取：
   - **App ID**（格式：`cli_xxxxxxxxxx`）
   - **App Secret**（点击查看，请妥善保管）

### 第二步：配置权限

进入应用的**权限管理**页面，开启以下权限：

| 权限 | 说明 | 是否必须 |
|------|------|------|
| `im:message.receive_v1`（接收消息事件） | 接收用户发送的消息 | 必须 |
| `im:message`（发送消息） | 向用户/群组发送回复 | 必须 |
| `im:message.reactions:write_only`（添加消息表情回应） | 收到消息后回复 👍 表情表示已读 | 可选 |
| `im:resource`（获取媒体资源） | 下载图片/文件附件 | 可选 |

配置完权限后，点击**申请权限**，等待管理员审批（自建应用通常立即生效）。

### 第三步：开启事件订阅

1. 进入应用的**事件与回调** → **添加事件**
2. 搜索并订阅 `im.message.receive_v1`（接收消息事件）
3. **连接方式**选择 **长连接**（WebSocket），无需配置回调 URL
4. 保存配置

> **说明：** 本应用采用 WebSocket 长连接方式接收事件，不需要公网服务器或回调地址，更简单安全。

### 第四步：在应用中配置

1. 在 Moonton Claude Desktop 中，进入 **Bot 管理** 面板
2. 创建一个新的 Bot 或进入已有 Bot 的设置
3. 右键 Bot → **渠道配置** → 选择**飞书**标签页
4. 填入以下信息：

| 字段 | 说明 | 是否必填 |
|------|------|------|
| **App ID** | 飞书应用的 App ID | 必填 |
| **App Secret** | 飞书应用的 App Secret | 必填 |
| **Chat ID** | 默认发送目标的群组/用户 ID（用于主动推送消息） | 可选 |
| **回复所有群消息** | 关闭时只响应 @机器人 的消息；开启时响应群内所有消息 | 可选 |

5. 点击**测试连接**，确认状态变为**已连接**
6. 开启**启用飞书渠道**，保存配置

#### 获取 Chat ID

如需使用主动推送功能（定时消息），需要提供目标群组或用户的 Chat ID：

- **群组 Chat ID**：在飞书群信息页面 → 链接中提取，或通过机器人发送消息后从后台日志查看
- **用户 Chat ID**：通过飞书 API `https://open.feishu.cn/open-apis/im/v1/chats` 查询

## 消息处理逻辑

### 支持的消息类型

| 类型 | 说明 |
|------|------|
| `text` | 纯文本消息 |
| `image` | 图片（下载到本地，显示为 `[图片]` 占位符） |
| `post` | 富文本消息（自动转换为 Markdown 格式） |
| `file` | 文件附件 |
| `audio` | 语音消息 |
| `video` / `media` | 视频/媒体文件 |
| `sticker` | 表情包（忽略，不处理） |

### 消息队列机制

当 Bot 正在处理上一条消息时，新消息会进入队列：

- 队列容量：每个 Bot 最多 **50 条**
- 消息有效期：**10 分钟**（超时自动丢弃）
- Bot 空闲后自动批量处理队列中的消息

### 回复格式

Bot 的回复以**飞书卡片**（Interactive Card）格式发送，支持：

- Markdown 文本渲染（代码块、加粗、斜体等）
- 超长内容自动分块（单块最大 4000 字符，总卡片不超过 28KB）
- 内容过长时显示截断提示：`...[消息过长，已截断]`

### 防卡死机制

处理消息时有两层保护：

1. **无活动看门狗**：如果 Bot 超过 3 分钟没有任何输出，自动强制重置会话
2. **进度提示**：如果处理超过 1 分钟，Bot 会向飞书发送"⏳ 正在处理中，请稍候..."的提示消息

## 定时器功能

右键 Bot → **定时配置** 进入定时任务设置，支持两种模式：

### 固定间隔模式

每隔指定分钟数发送一条消息，支持添加多条独立配置：

| 字段 | 说明 |
|------|------|
| 间隔分钟 | 每隔多少分钟触发一次 |
| 消息内容 | 留空则使用全局默认消息 |
| 目标 Chat ID | 留空则使用渠道默认 Chat ID |

### 固定时间模式

在每天的指定时刻发送消息：

| 字段 | 说明 |
|------|------|
| 时间 | 格式 `HH:mm`，如 `09:00` |
| 重复日期 | 每天 / 工作日 / 周末 / 自定义星期 |
| 消息内容 | 留空则使用全局默认消息 |
| 目标 Chat ID | 留空则使用渠道默认 Chat ID |

每种定时配置可以设置**全局默认消息**，作为各条目未单独配置时的回退值。

## 高级配置

### 只响应 @提及

默认情况下，Bot 在群组中**只响应 @机器人 的消息**，不干扰正常群聊。如需让 Bot 回复群内所有消息，开启**回复所有群消息**选项。

### 私聊自动回复

Bot 会自动回复所有发给它的私信，无需 @。

### 附件下载

收到图片或文件时，Bot 自动下载至本地缓存目录：

```
~/.MoontonClaudeDesktop/cache/feishu_downloads/{message_id}/{filename}
```

### 数据存储位置

| 数据 | 路径 |
|------|------|
| 渠道配置（含 App Secret） | `~/.MoontonClaudeDesktop/bots/{botId}/channels.json` |
| Bot 对话记录 | `~/.MoontonClaudeDesktop/bots/{botId}/conversation.json` |
| Bot 长期记忆 | `~/.MoontonClaudeDesktop/bots/{botId}/CLAUDE.md` |
| 下载的图片/文件 | `~/.MoontonClaudeDesktop/cache/feishu_downloads/` |

## 常见问题

**Q：点击测试连接后一直显示"连接中"？**

- 检查 App ID 和 App Secret 是否填写正确
- 确认飞书应用的权限已申请并通过
- 检查网络是否能访问 `open.feishu.cn`

**Q：Bot 在群里不回复消息？**

- 确认已将机器人添加到该群组
- 若**回复所有群消息**未开启，需要 @机器人 才能触发回复
- 在飞书开放平台确认 `im.message.receive_v1` 事件已订阅

**Q：Bot 修改了描述，但行为没有变化？**

- 修改 Bot 配置后，需要**停止并重新启动** Bot 才能生效

**Q：回复内容格式混乱？**

- 飞书卡片不支持 `#` 开头的标题语法，本应用会自动将其转换为加粗文本
- 代码块会被完整保留，不会在中间截断

**Q：如何让 Bot 记住某些信息？**

- Bot 有独立的 `CLAUDE.md` 记忆文件，可以直接告诉 Bot "请记住..."，Bot 会自动写入
- 每 8 轮对话会自动整理一次记忆，保持简洁

**Q：如何获取应用的 App Secret？**

进入飞书开放平台 → 应用详情 → **凭证与基础信息** → 点击 App Secret 旁的查看按钮。App Secret 属于敏感信息，请妥善保管。

**Q：定时消息发送失败？**

- 确认目标 Chat ID 填写正确
- 确认 Bot 已被添加到目标群组
- 检查 Bot 渠道连接状态是否为**已连接**
